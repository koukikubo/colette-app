# RF日次化とダッシュボード簡略化（2026-11-14）

ブランチ：`feat/daily-rf-and-dashboard-summary`。

## 変更

- RF定期実行を毎月1日から毎日03:00（Asia/Tokyo）へ変更し、当日を計算基準日にする。
- DailyRfUpdateJobは初回の実行日を再試行にも引き継ぐ。scheduled_onの一意制約と共通RFロックで同じ日の重複を防ぎ、翌日は新しい履歴を作る。
- 計算・適用処理はAutomaticUpdaterへ共通化。手動適用/復元との版番号競合、失敗時に現在適用中の結果を保持する動作を維持する。
- 旧月次履歴と再配信用のMonthlyRfUpdateJobは保持。旧月次の定期スケジュールは停止し、新しい日次スケジュールだけを登録する。
- 計算履歴には日次自動と実行日を表示する。既存のmonthly_apply_state/errorはAPI互換のため日次でも共用する。
- 比較候補APIは店舗日付のcurrent_monthを返す。比較画面は条件なしでも当月を終了月として比較し、当月履歴がない場合に古い月を代用しない。
- 「比較できる適用済み履歴」の一覧表示を除去。開始月・終了月の自由入力と、比較処理に使う履歴候補取得は維持する。
- ダッシュボードは件数・人数と予約管理への導線を残し、未完了予約の個別一覧、RF情報、日付/最終取得時刻を除去する。前の変更で停止した定期・フォーカス復帰時更新も追加していない。
